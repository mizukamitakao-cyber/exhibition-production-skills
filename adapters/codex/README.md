# Codex VS Code アダプター

## アーキテクチャ

Codex アダプターは 2 層構造で設計する。

| 層 | ファイル | 役割 | 対応するClaude Code側 |
|---|---------|------|--------------------|
| 指示層 | `generate-instructions.py` → `AGENTS.md` | Codex に全スキルの指示を提供 | `CLAUDE.md` |
| 実行層 | `generate-skills.py` → Codex Skills形式 | 個別スキルの実行機構 | `.claude/skills/*/SKILL.md` |
